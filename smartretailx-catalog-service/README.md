# SmartRetailX - Product Catalogue Service

## Overview
Manages global product catalogue items, categories, descriptions, images, and prices for the SmartRetailX Commerce Platform.

## Features
- **Endpoints**: List products (`GET /api/v1/catalog`), Product details (`GET /api/v1/catalog/{id}`), Create product (`POST /api/v1/catalog`), Update product (`PUT /api/v1/catalog/{id}`), Delete (`DELETE`).
- **Database**: PostgreSQL with SQLAlchemy ORM.
- **Port**: `8002`
