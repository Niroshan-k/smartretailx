# SmartRetailX - User Management Service

## Overview
The User Management Service handles authentication, registration, JWT token generation, and user profile management for the SmartRetailX Commerce Platform.

## Features
- **RESTful Endpoints**: User registration (`/register`), Login (`/login`), Profile (`/me`).
- **Security**: Password hashing with Bcrypt, JWT Bearer Token authorization.
- **Database**: PostgreSQL with SQLAlchemy ORM.
- **OpenAPI**: Swagger UI documentation at `/docs`.

## Port
`8001`
